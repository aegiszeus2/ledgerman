LEDGERMAN — PROJECT SUMMARY
===========================
Last updated: 2026-03-14

PURPOSE
-------
Multi-tenant SaaS construction management platform.
Started as Belfort's invoicing tool — now a standalone product.
Target: small contractors who can't afford Procore ($375+/mo).
Price: $25/month per company.

STATUS
------
ACTIVE — Phase 2 complete. Backend live locally, cloud deployment next.

STACK
-----
Frontend:  Pure HTML/CSS/JS, in-memory cache, localStorage fallback, IndexedDB photos
Backend:   Python 3 / Flask REST API, SQLite, JWT auth, TOTP 2FA
Deploy:    Netlify (frontend) — backend needs cloud hosting (Render/PythonAnywhere)

KEY FEATURES COMPLETE
---------------------
- Multi-tenant isolation (company_id scoped, server-enforced)
- JWT authentication (admin + worker + approver roles)
- Worker invite system (server-issued one-time tokens, 7-day expiry)
- 2FA / TOTP (Google Authenticator / Authy, verified server-side)
- Clock In / Clock Out (auto-rounds to nearest 15 min, method badge on approvals)
- Email collection on first worker login
- LittleShield super admin console (diagnostics, company management)
- Automated daily backups (cron 2AM, 30-day retention)
- Portable zip (full transfer including live database)
- System guide + org chart (LEDGERMAN-SYSTEM-GUIDE.html)
